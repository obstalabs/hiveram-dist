# Security Policy

## Reporting a vulnerability

Email security@obstalabs.dev. Do not open a public issue or discussion.

## What to include

- Affected version
- Steps to reproduce
- Impact
- Whether it is already public

## What happens next

We send a first reply within two business days (Monday to Friday, UTC+8, public holidays excepted).

## Supported versions

Security fixes ship in the latest release on the 0.x line; upgrade to the latest release.
